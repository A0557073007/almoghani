# Almoghani Personal Website

ملفات موقع شخصي عربي بتصميم أسود وذهبي.

## الملفات
- `index.html`
- `styles.css`
- `script.js`

## تعديل الصورة
حاليًا يوجد مكان مخصص للصورة داخل التصميم.
يمكن لاحقًا إضافة صورة باسم `ahmed.jpg` وتعديل قسم الصورة في `index.html`.

## GitHub Pages
ارفع الملفات إلى المستودع، ثم:
Settings → Pages → Deploy from a branch → main / root → Save
